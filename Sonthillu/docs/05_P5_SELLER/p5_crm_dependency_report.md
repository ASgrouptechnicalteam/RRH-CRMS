# P5 CRM Dependency Report

**Status:** PENDING CRM TEAM REVIEW
**Date:** 2026-08-21
**Phase:** Sonthillu V1 Phase P5 (Seller / Sell Property)

## Context

Sonthillu P5 has implemented the frontend and backend validation for the seller property submission flow. To uphold the security boundary, Sonthillu will not process or write to the live property database. We require a CRM intake endpoint to receive, review, and ultimately publish these seller drafts.

Currently, Sonthillu's `submitSellerPropertyDraft` adapter explicitly returns a `CRM_DEPENDENT` error until this contract is established.

## Required Information from CRM Team

### 1. Endpoint Details

- **Method:** (e.g., `POST`)
- **Path:** (e.g., `/api/v1/seller/intake`)
- **Authentication:** Will this use the existing system-to-system `CRM_API_KEY` in headers, or a customer-specific JWT? (Sonthillu prefers the system-wide key for backend-to-backend operations).

### 2. Request Schema

What is the exact JSON structure expected? We currently collect:

- Title
- Expected Price
- City
- Locality
- Description
- Property Type
- Listing Type
- BHK (Optional/NA)
- Area (Optional)

### 3. Customer Identity/Ownership Mechanism

How should we securely transmit the `customerId` so the CRM associates the property draft with the correct owner without trusting browser inputs?

### 4. Media Contract

How will images be uploaded?

- Option A: Multipart/form-data directly to CRM.
- Option B: Pre-signed S3 URLs generated by CRM and returned to Sonthillu client.
- Option C: Base64 strings in JSON payload (Not recommended for size).

### 5. Idempotency Contract

We are sending an `idempotencyKey` string. Does the CRM guarantee that retrying with the same key within a 24-hour window will not duplicate the property draft?

### 6. Response Schema

What will the CRM return on success?

- e.g., `{ success: true, submissionId: string }`

### 7. Lifecycle & Moderation

How will Sonthillu know when a property transitions from "Pending Review" to "Published" or "Rejected"?

- Option A: CRM sends a webhook back to Sonthillu.
- Option B: Sonthillu polls a CRM status endpoint.
